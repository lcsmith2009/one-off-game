# ONE OFF — itch.io upload and launch

The upload file is **one-off-itch.zip**. It contains one self-contained `index.html`. The equivalent `one-off-itch.html` is also included; upload one playable build, not both.

## Owner actions

1. Sign in to itch.io in your normal browser. If you need a free account, create it, accept its terms yourself, and verify your email if requested. This session reached a persistent itch.io security-verification page before the editor, so no account status could be inspected and no draft was created.
2. Create a new game as a **private draft**. Use `ITCH-LISTING.md`, upload `one-off-itch.zip`, and select **This file will be played in the browser**. Add the cover and screenshots from this package.
3. Use HTML/browser classification. For a strict $0 launch, select **No payments**. Leave seller/payment enrollment unchanged. Set the mobile-friendly option, enable the fullscreen button, and allow scrollbars. A 480 × 900 desktop embed is a suitable starting size. Mobile launch should use fullscreen.
4. Preview the uploaded build on itch.io. Check home → Daily → all five rounds → results → Practice → Home. Check sharing, and remember that itch.io's separate host starts with separate local records. The package itself passed live-browser tests, but this final itch-hosted preview is blocked by account access.
5. Complete the AI Disclosure section as described in `ITCH-LISTING.md`. Keep the draft private until you approve the final page. Choose **Public** and save/publish only when you are ready to release it.

No listing has been published, no payment account has been created, and no expenses have been incurred by this work.
