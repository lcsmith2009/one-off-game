# ONE OFF — player instructions

**Miss perfectly.** Land exactly one above or below the target. For target 73, 72 and 74 win. The target itself and all other numbers lose the round.

Every run has five rounds: Pick One, Type It, Slide It, Quick Tap, then Pick One again. A wrong answer does not end the run. A 5/5 result is **PERFECTLY WRONG**.

1. Pick One: tap or click your choice.
2. Type It: enter a whole number; choose LOCK IT or press Enter. Blank/invalid text is not scored.
3. Slide It: drag the slider and choose LOCK IT. Keyboard users can use arrows, Home and End.
4. Quick Tap: choose TAP TO START. After the ready pause, catch the changing number exactly one away. There is one pass.
5. Choose NEXT after each round and SEE SCORE after the fifth.

Use Tab to move through controls and Enter/Space to activate buttons. The stats dialog closes with Escape or Close stats. Quick Tap is a visual timing challenge; a screen-reader-only alternative is not included in this release.

Daily uses your local calendar date. The first completed score is kept; replays are labeled and cannot replace it. Practice gives another set of numbers without extending your daily streak. Finish Daily on consecutive dates to grow the streak. Fastest-perfect records count only 5/5 runs. Run time includes reading and waiting.

SHARE RESULT opens native sharing when available, otherwise copies the result. If copying is blocked, selectable text appears. No challenge numbers are included in the shared score.

Records stay in the current browser and host. Clearing site data can erase them. Private/embedded browser restrictions may prevent saving. GitHub Pages and itch.io do not sync records.

For a downloaded single-file copy, open `one-off-itch.html` in a modern browser. It contains all code and styles and needs no network to play. Browser storage and sharing permissions vary for local files. The hosted version is recommended for consistent records.
