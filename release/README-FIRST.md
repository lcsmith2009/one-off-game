# ONE OFF — launch kit

The finished game is live: https://lcsmith2009.github.io/one-off-game/

- **Upload to itch.io:** `one-off-itch.zip` (one self-contained index.html).
- **Single-file alternative:** `one-off-itch.html`.
- **Start with:** `ITCH-UPLOAD-GUIDE.md` and `ITCH-LISTING.md`.
- **Graphics:** `assets/` contains the cover and optional banner.
- **Screenshots:** `screenshots/` contains six actual browser captures cropped to the game.
- **Validation:** `QA-REPORT.md` describes all passing checks and their limits.
- **Monetization:** `LAUNCH-OPTIONS.md`; no payment setup was activated.
- **Player help:** `PLAYER-INSTRUCTIONS.md`.
- **Optional posts:** `PROMOTIONAL-COPY.md`; nothing has been sent or posted.

Keep the itch.io listing private until you approve publication. This browser was blocked at itch.io's sign-in security check, so the private draft could not be created here. The guide contains the account, upload, preview, and publication steps for your normal browser.
