# ONE OFF — $0-upfront launch options

Researched October 18, 2026. **Spent: $0.** No payment processor, marketplace listing, subscription, or advertising was activated. No sales, customers, or revenue were verified.

## Recommendation

Keep the verified GitHub Pages game live. Prepare one itch.io page with free browser play, then enable optional support only after the owner approves payment setup. The complete HTML5 build, listing copy, screenshots, and graphics are included. This is a launch recommendation, not evidence of demand or a revenue forecast.

| Option | Upfront platform cost | Fit for ONE OFF | Decision |
| --- | --- | --- | --- |
| Existing GitHub Pages | Existing $0 hosting | Immediate shareable game; no checkout | Keep current deployment |
| itch.io HTML5 | Free hosting/listing; transaction fees if support payments are enabled | Best fit for browser play and game discovery; HTML5 support payments are donations | First marketplace candidate |
| Ko-fi Free tips | $0 monthly; 0% platform fee on one-time tips in Free mode, plus processor fees | Optional support link beside the existing game; no integrated game discovery | Secondary candidate after account/payment approval |
| Gumroad download | No monthly charge; published direct-sale fee 10% + $0.50, Discover 30% | Suits a downloadable HTML file; more friction for a tiny browser game | Lower priority |

Ko-fi currently starts new creators in Standard mode, with a 5% service fee; Free mode must be selected for 0% one-time-tip platform fees. Processor charges still apply. No Ko-fi account or link was created.

## itch.io payment decision

Use **No payments** for a launch with no financial setup. After approval, optional donations can preserve free play. A $3 suggested support amount is a proposed experiment, with no premium features promised.

“Direct to you” requires connecting a payment provider and supplying required information; the creator acts as merchant of record. “Collected by itch.io” handles that role, but its documentation includes a one-time **$3 tax-identity adjustment**, a **$5** eligible-balance minimum, a **7-day** transaction waiting period, and payout review. Neither method is enabled here. Fees and financial terms require owner review; the collected-payout path is excluded under the current no-spending rule.

## Free promotion prepared

Use the short copy in `PROMOTIONAL-COPY.md` with the live link and actual screenshots. Post only to channels where the owner wants to share it. No messages, social posts, ads, unsolicited outreach, or review requests were sent.

Keep the game free while learning whether people return and voluntarily support it. Use the marketplace's own dashboard after launch to inspect actual activity; there is no analytics code in the game and no audience size is assumed.
